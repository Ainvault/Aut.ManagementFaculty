# صفحه ۶ — Faculty

**URL:** https://mitsloan.mit.edu/faculty/faculty-directory  
**نقش:** دایرکتوری searchable اساتید

## ساختار مشاهده‌شده
- صفحه طولانی فهرست اساتید (حجم بالا؛ صدها ورودی)
- هر ورودی معمولاً: نام · سمت/عنوان · لینک پروفایل
- فیلتر/جستجو در UI زنده (بر اساس تخصص/نام)

## الگوی پروفایل استاد (برگ)
از لینک‌های کارت faculty در صفحات برنامه:
- نام کامل
- عنوان آکادمیک
- بیو کوتاه
- حوزه‌های پژوهش
- گاهی لینک آزمایشگاه/مرکز

## ارتباط با Press
صفحه Press از Media Relations برای اتصال خبرنگاران به faculty استفاده می‌کند → [11-utility-footer.md](./11-utility-footer.md)
